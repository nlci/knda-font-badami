About this project

NLCI Kannada is two font families for the Kannada script - Badami and Kaveri.

To use the halant as a vowel (which is needed for some languages) please see the FAQ.

Future plans

Please send us your requests using GitHub issues. If you are interested in helping us make the fonts better see the Developer page.
