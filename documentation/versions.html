NLCI Kannada - Versions and Changes

Current version

The latest released version of the fonts is always available from the Badami release page as a .zip archive for all major platforms.

In addition to released versions, the most recent development build is also on the release page.

Previous versions

Previous versions remain available from the release page.

A detailed list of changes for each version of the fonts is on the Version history page.
