## Current version

The latest released version of the fonts is always available from the [Badami release page](https://github.com/nlci/knda-font-badami/releases) as a .zip archive for all major platforms.

In addition to released versions, the most recent [development build](https://github.com/nlci/knda-font-badami/releases/tag/dev) is also on the release page.

## Previous versions

Previous versions remain available from the [release page](https://github.com/nlci/knda-font-badami/releases).

## Change history

A detailed list of changes for each version of the fonts is on the [Version history page](history.md).
